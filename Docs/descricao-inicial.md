# ARDAP — Descrição inicial

## Descrição do projeto

Sistema web para digitalizar os formulários de papel da Associação Recanto
dos Animais em Perigo (Paulo Afonso/BA).

## Ideia principal do projeto

Substituir papel por sistema centralizado com login por papéis
(Admin/Funcionário), assinatura digital e relatório mensal p/ prefeitura.

## Público alvo

Equipe interna da ONG (~4 usuários). Sem fluxo público.

## Problemas solucionados com a aplicação

- Formulários dispersos em papel
- Sem histórico centralizado por animal
- Sem controle de acesso
- Relatório mensal manual
